# پروژه تولید هوشمند فلش کارت زبان ژاپنی به فارسی

📌 **مقدمه**  
این پروژه با هدف ایجاد یک وب‌سایت برای تولید فلش‌کارت‌های هوشمند جهت آموزش زبان ژاپنی به فارسی طراحی شده است. در فاز اول، تمرکز بر روی ساخت یک محصول اولیه (MVP) با استفاده از فناوری‌های رایگان و کم‌هزینه خواهد بود.

🛠 **فناوری‌های پیشنهادی**  
1. **Frontend (رابط کاربری)**  
   - React.js → کتابخانه قوی برای ساخت رابط کاربری داینامیک  
   - Tailwind CSS → برای طراحی سریع و ریسپانسیو  
   - Axios → برای ارسال درخواست به سرور  
   
2. **Backend (سمت سرور)**  
   - Node.js + Express.js → فریمورک سریع و سبک برای مدیریت درخواست‌ها  
   - Python (Flask) → در صورت نیاز برای پردازش‌های AI  
   
3. **هوش مصنوعی (AI)**  
   - Hugging Face Models → مدل‌های رایگان برای پردازش زبان طبیعی  
   - Google Translate API (پلن رایگان) → برای ترجمه اولیه  
   
4. **دیتابیس**  
   - MongoDB Atlas → دیتابیس ابری رایگان برای ذخیره فلش‌کارت‌ها  
   
5. **استقرار (Deployment)**  
   - Vercel → برای استقرار فرانت‌اند  
   - Render.com → برای استقرار بک‌اند  

🚀 **مراحل توسعه**  
1. طراحی رابط کاربری ساده با React و Tailwind CSS  
2. راه‌اندازی سرور با Node.js و Express.js  
3. اتصال به API هوش مصنوعی برای تولید محتوا  
4. ذخیره فلش‌کارت‌ها در MongoDB  
5. استقرار پروژه بر روی Vercel و Render  

📊 **جدول فناوری‌ها**  
| بخش        | فناوری                        | وضعیت |
|------------|--------------------------------|--------|
| Frontend   | React.js + Tailwind CSS + Axios | ✅     |
| Backend    | Node.js + Express.js           | ✅     |
| AI         | Hugging Face API               | ✅     |
| دیتابیس    | MongoDB Atlas                  | ✅     |
| استقرار    | Vercel / Render                | ✅     |
