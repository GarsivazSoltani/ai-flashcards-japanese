# AI Flashcards Japanese

## پروژه:
پروژه "AI Flashcards Japanese" یک اپلیکیشن برای یادگیری زبان ژاپنی با استفاده از فلش‌کارت‌ها است. این پروژه از API های یادگیری ماشین برای تولید فلش‌کارت‌ها با ترجمه‌های خودکار استفاده می‌کند.

## هدف:
هدف از این پروژه ساخت یک سیستم یادگیری فلش‌کارت برای تمرین واژگان و جملات زبان ژاپنی است. این سیستم از مدل‌های مبتنی بر یادگیری ماشین برای ترجمه و تولید جملات استفاده می‌کند.

## ویژگی‌ها:
- استفاده از API برای ترجمه متن‌ها.
- ذخیره‌سازی فلش‌کارت‌ها در مدل.
- رابط کاربری ساده برای نمایش فلش‌کارت‌ها.
- امکان مرور و بررسی آخرین بار که فلش‌کارت بررسی شده است.

## ساختار پروژه:
- `models/flashcardModel.js`: مدل داده‌ای فلش‌کارت.
- `views/flashcardView.js`: نمایش فلش‌کارت‌ها.
- `controllers/flashcardController.js`: منطق پردازش فلش‌کارت‌ها.
- `huggingFaceApi.js`: ارتباط با API های ترجمه.

## مراحل پیشرفت:
1. ایجاد مدل فلش‌کارت.
2. راه‌اندازی ارتباط با API برای ترجمه.
3. ایجاد ساختار MVC.
4. توسعه رابط کاربری.
5. اتصال به پایگاه داده و ذخیره فلش‌کارت‌ها.
